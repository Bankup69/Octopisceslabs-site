# OctoPisces Labs site: project notes

Read this first. Keep it short: it loads every session.

## Every session
- Start: `git pull origin main`. Browser (claude.ai) sessions push to `claude/*` branches; if one is unmerged, tell the owner before editing.
- Finish: add a dated entry at the top of `CHANGELOG.md`, commit, push to `main`. GitHub Pages redeploys in about a minute.
- Save tokens: README.md has the full map. Open only the files the task needs. Never read files in `media/` or `img/` (videos and images).
- Owner is non-technical: plain language, exact steps.

## Rules
- `rental-calc/` is copied from the Rental-Income-Calculator repo. Don't edit it here.
- Calculator guide pages are generated by `tools/build_calculators.py`. Edit the script, not the pages.
- Next Set legal and support pages are hand-made; when Next Set's `legal/` text changes, update them here too.
- Add new pages to `sitemap.xml`.
- `/how-to/` (video walkthroughs) is generated by `tools/build_howto.py` from a manifest of recorded videos. Edit the script, not the page.
- End of task: record new decisions here and add a one-line lesson under "Lessons learned" for any mistake that got fixed.

## Lessons learned

One line per fixed mistake, newest first.

- 2026-11-08: Metricool copies media when a post is scheduled. Replacing a file on the site does not change scheduled posts: give the new file a new name and update every post with updateScheduledPost.
- 2026-11-08: The AI voice said "air-binb". In narration write "Air B N B" (captions show "Airbnb"). Logos on video end cards must be keyed (no navy box): use `tools/video/edu/logo_keyed.png`.
- 2026-11-06: The AI voice said "octo-puss-ees". Brand is said octo-pie-sees. In any narration write it "octo pie sees labs" and check the phonemes (kokoro_onnx Tokenizer.phonemize) before building.
- 2026-11-04: Home page app card pointed at `rental-calc/icons/icon.svg` after that file was retired. When rental-calc assets change, grep the site for old paths.

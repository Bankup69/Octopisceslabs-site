# OctoPisces Labs website

Studio site for OctoPisces Labs, served by GitHub Pages at https://octopisceslabs.com.

- `index.html`: home page with the playable octopus boss fight (all code inline, no build step)
- `privacy.html`: studio-wide privacy policy
- `next-set/`: Next Set marketing page and screenshots (`next-set/img/`)
- `next-set-support/`, `next-set-delete-account/`, `next-set-terms/`, `next-set-privacy/`, `next-set-health/`, `next-set-ai/`: Next Set support and legal pages for the App Store and Google Play
- `rental-calc/`: the Rental Calc web app. Don't edit here: it's copied from the Rental-Income-Calculator repo by its `scripts/publish-site.sh`
- `img/`: logo mark, favicon, home-screen icon, link-preview image and full logo
- `CNAME`: custom domain for GitHub Pages

To update the site, replace the files and push to `main`. Pages redeploys in about a minute.
